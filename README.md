# Moori Sushi - Online Ordering Web Application

Welcome to the official repository for **Moori Sushi**, a modern, full-stack Japanese restaurant online ordering platform. This application allows customers to browse authentic sushi menus, customize orders, manage discount coupons, and submit feedback or picture-attached complaints seamlessly.

---

## Features

- **Interactive Menu & Ordering:** Browse categorized Japanese dishes (rolls, nigiri, sashimi, bento boxes, ramen, and drinks) with real-time cart management.
- **Online Checkout & Delivery Tracking:** Streamlined checkout workflow for delivery or pickup orders.
- **Coupon & Promo Code System:** Apply valid discount codes at checkout for instant savings.
- **Customer Feedback & Complaint Management:** Dedicated support system allowing users to file structured complaints with attached pictures. 

---

## Tech Stack

- **Frontend:** React, TypeScript / JavaScript, Vite, Tailwind CSS
- **Backend:** Node.js / Express (or integrated API handlers)
- **Database:** MySQL / Local persistence

---

## Getting Started Locally

Follow these instructions to get a copy of the project running on your local machine for development and testing.

### Prerequisites

Make sure you have the following installed on your system:
- **Node.js** (v18 or higher recommended)
- **npm** or **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/nuri-sushi-web.git
   cd nuri-sushi-web
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and configure your backend API endpoints and environment keys:
   ```env
   VITE_API_URL=http://localhost:5000
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000` (or the port specified in your terminal).
